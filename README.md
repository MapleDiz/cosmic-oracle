# Cosmic Oracle ✦

Адаптивное одностраничное приложение с астрологическими интерпретациями. Работает на HTML, CSS и JavaScript; расчёты выполняются на устройстве, профиль хранится в localStorage.

## Открыть приложение

GitHub Pages: https://maplediz.github.io/cosmic-oracle/

## Возможности

- 12 знаков зодиака;
- отдельные прогнозы на день, неделю, месяц и год;
- калькулятор совместимости двух имён и знаков зодиака;
- отдельные символические оценки для любви, семейной жизни, совместной работы и быта;
- пояснения о нумерологических числах имён, сходстве стихий, сильных сторонах пары и темах для разговора;
- возможность сравнивать нескольких потенциальных партнёров, сохраняя первый профиль и меняя второго человека;
- вариативные тексты по отношениям, работе, финансам и внутреннему балансу;
- кнопка «Другой вариант» формирует новую интерпретацию, не меняя вычисленное положение небесных тел;
- положение Солнца, Луны и планет рассчитывается локально библиотекой [Astronomy Engine](https://github.com/cosinekitty/astronomy), основанной на астрономических моделях VSOP87 и NOVAS;
- лунная фаза и основные аспекты транзитных планет к солнечной точке рождения;
- солнечные дома используются как упрощённая техника, потому что полная натальная карта требует точного времени и места рождения;
- космический фон, параллакс мышью/гироскопом и адаптация под мобильные устройства;
- персональные данные остаются в localStorage браузера.

## Важные ограничения

Это не профессиональная консультация и не научный способ предсказывать события. Астрологические значения — символическая интерпретация реальных астрономических положений. В текущей версии нет точного времени и места рождения, поэтому не рассчитываются асцендент и индивидуальные дома. Не принимайте финансовые, медицинские или другие важные решения только на основе прогноза.

## Лицензия библиотеки

В проект включена assets/astronomy.browser.min.js из проекта Astronomy Engine; исходный файл содержит уведомление MIT и текст лицензии.

## Локальный запуск

Откройте index.html в браузере. После изменений в GitHub Pages обновлённая версия появится после завершения публикации. Для гироскопа на мобильном устройстве открывайте HTTPS-сайт и разрешите доступ к датчикам, если браузер спросит.
