# Cosmic Oracle ✦

Адаптивное одностраничное приложение с персональными развлекательными астрологическими прогнозами. Работает на HTML, CSS и JavaScript без сборки и сторонних библиотек.

## Открыть приложение

После публикации GitHub Pages: https://maplediz.github.io/cosmic-oracle/

## Запуск локально

Откройте `index.html` в браузере. Для гироскопа на телефонах используйте опубликованный HTTPS-адрес и разрешите доступ к датчикам движения, если браузер спросит.

## Возможности

- 12 знаков зодиака;
- прогнозы на день, неделю и год;
- детерминированный выбор текста прогноза для имени, даты рождения и периода;
- хранение профиля только в `localStorage` браузера;
- космический фон, движение звёзд и параллакс мышью/гироскопом;
- адаптация под мобильные устройства и reduced motion.

Прогнозы носят развлекательный характер.
